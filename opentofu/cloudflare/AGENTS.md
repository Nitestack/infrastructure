# Cloudflare Edge

This directory manages Cloudflare DNS, zone settings, DNSSEC, and redirect
rules for `npham.de` and `nhanph.am`, separately from the NixOS configuration.
Shared hardening lives in `modules/zone-baseline`; each zone has its own
`zone-*.tf` with a record map. Cloudflare Tunnel ingress remains generated by
`modules/nixos/homelab/cloudflared.nix`.

Use the repository dev shell, initialize only when needed, and inspect a plan
before applying:

```sh
nix develop
tofu init
tofu plan
tofu apply
```

Supply the API token through the secret-safe mechanism in the local README. Do
not print it, commit it, put it in Terraform configuration, or use shell command
substitution to decrypt it. Keep the tunnel identifier synchronized with
`configurations/nixos/homestation/default.nix` when either side intentionally
changes.

If adopting an existing Cloudflare object, import it first and require a
no-change plan before applying. Do not mix an OpenTofu state change with an
unrelated NixOS activation. Never disable DNSSEC or change nameservers before
the registrar's DS record is removed.
